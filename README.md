RU
1: Внесите ваш API-ключ в файл 'config.template.py' и переименуйте его в 'config.py.'
2: Установите необходимые зависимости из файла req.txt, выполнив команду 'pip install -r req.txt'
3: Запустите скрипт через командную строку (cmd) с помощью команды 'python screen_helper.py'
EN
1: Insert your API key into 'config.template.py' and rename it to 'config.py'
2: Install everything from 'req.txt' using the command 'pip install -r req.txt'
3: Run the file via cmd using the command 'python screen_helper.py'
